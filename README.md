## 📖 Acerca del Proyecto

**SearchPineapple** es una plataforma web desarrollada para ayudar a los usuarios a encontrar y comparar los mejores precios en equipos y accesorios tecnológicos en tiendas y locales comerciales de Ecuador. Proporciona información actualizada de productos, ubicaciones, catálogos y videos demostrativos de cada tienda.

---

## ✨ Características Principales

- 🛒 **Comparador de Locales**: Acceso rápido a las mejores tiendas de tecnología con reseñas y catálogos de productos.
- 💻 **Catálogo de Productos**: Información detallada de computadoras, laptops, periféricos, celulares y accesorios con precios referenciales.
- 🎥 **Contenido Multimedia**: Videos y recorridos virtuales de los locales y sus productos.
- 📱 **Diseño Responsive**: Adaptable a dispositivos móviles, tablets y computadoras de escritorio.
- 🌐 **Navegación Intuitiva**: Menú dinámico, animaciones fluidas al desplazarse y acceso directo a redes sociales.

## 🚀 ¿Cómo Ejecutar el Proyecto?

Este proyecto está construido con tecnologías web estándar (HTML/CSS/JS), por lo que no requiere instalación de dependencias pesadas:

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/FranciscoArias10/SearchPineapple.git
   cd SearchPineapple
   ```

2. **Abrir en tu navegador:**
   - Puedes abrir directamente el archivo `index.html` en cualquier navegador web moderno (Chrome, Firefox, Edge).
   - O usando la extensión **Live Server** en Visual Studio Code.
   - O mediante un servidor HTTP simple de Python:
     ```bash
     python3 -m http.server 8000
     ```
     Luego visita `http://localhost:8000` en tu navegador.
